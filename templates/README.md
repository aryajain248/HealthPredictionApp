# Health Prediction App

## Overview

A Flask-based Health Prediction Application that stores patient records and predicts possible health risks based on blood test values.

## Features

* Create Patient Records
* View Patient Records
* Update Patient Records
* Delete Patient Records
* Email Validation
* Date of Birth Validation
* Blood Value Validation
* Health Risk Prediction
* SQLite Database Storage
* Bootstrap User Interface
* Patient Counter

## Technology Stack

* Python
* Flask
* SQLite
* HTML
* Bootstrap

## How to Run

1. Install Python
2. Install Flask

pip install flask

3. Run the application

python3 app.py

4. Open

http://127.0.0.1:5000
